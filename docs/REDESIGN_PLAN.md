# 프론트엔드 리디자인 계획

디자인 시안(Design 캔버스)의 화면을 실제 React 코드로 옮기는 작업 계획입니다.
작업 브랜치는 `feat/redesign`이고, 단계마다 커밋했습니다. **8단계 모두 끝났습니다.**

## 원칙

- **스타일:** Tailwind v4. 색·글자·모서리 값은 `src/index.css`의 `@theme` 토큰만 씁니다. 화면 코드에 색상 코드를 직접 쓰지 않습니다.
- **테마:** 라이트·다크 둘 다. 처음에는 OS 설정을 따르고, 헤더의 버튼으로 바꾼 값은 브라우저에 저장합니다. `<html data-theme="dark">`로 전환합니다.
- **반응형:** 768px 미만은 토스증권처럼 큼직한 카드와 하단 메뉴, 768px 이상은 업비트처럼 한 화면에 많은 정보.
- **티어 배지:** 이미지(webp) 대신 시안과 같은 SVG 컴포넌트(`TierBadge`) 하나로 그립니다.
- **점진 전환:** 기존 CSS 파일은 해당 화면을 옮길 때 지웠고, 기존 화면이 깨지지 않도록 미뤄 둔 Tailwind 기본 초기화(preflight)는 8단계에서 켰습니다. 이제 CSS 파일은 `src/index.css` 하나입니다.

## 정리 결과

- 화면 13개(메인, 거래소 목록·상세, 투자내역, 최신동향, 커뮤니티 목록·상세·글쓰기, 랭킹, 마이페이지·프로필 수정, 공지, 로그인)를 라이트·다크, 375px·1440px에서 열어 가로 넘침이 없는 것을 확인했습니다.
- 첫 화면 자바스크립트: 750kB → 351kB (메인에서 recharts 제거)
- 지운 것: 옛 CSS 30개 파일, 티어 webp 이미지 14개, react-icons·recharts 패키지
- 린트 경고 18개 → 0개
