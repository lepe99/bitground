# 프론트엔드 리디자인 계획

디자인 시안(Design 캔버스)의 화면을 실제 React 코드로 옮기는 작업 계획입니다.
작업 브랜치는 `feat/redesign`이고, 단계마다 커밋합니다.

## 원칙

- **스타일:** Tailwind v4. 색·글자·모서리 값은 `src/index.css`의 `@theme` 토큰만 씁니다. 화면 코드에 색상 코드를 직접 쓰지 않습니다.
- **테마:** 라이트·다크 둘 다. 처음에는 OS 설정을 따르고, 헤더의 버튼으로 바꾼 값은 브라우저에 저장합니다. `<html data-theme="dark">`로 전환합니다.
- **반응형:** 768px 미만은 토스증권처럼 큼직한 카드와 하단 메뉴, 768px 이상은 업비트처럼 한 화면에 많은 정보.
- **티어 배지:** 이미지(webp) 대신 시안과 같은 SVG 컴포넌트(`TierBadge`) 하나로 그립니다.
- **점진 전환:** 기존 CSS 파일은 해당 화면을 옮길 때 지웁니다. 그동안 기존 화면이 깨지지 않도록 Tailwind의 기본 초기화(preflight)는 마지막 단계에서 켭니다.

## 단계

| 단계 | 내용 | 시안 보드 |
|---|---|---|
| 1 | 기반: Tailwind v4, 디자인 토큰, 테마 전환, 공통 컴포넌트(로고·티어 배지·아바타·카드·버튼·탭·등락 숫자), 공통 레이아웃(PC 헤더·모바일 하단 메뉴) | 디자인 기준, 모든 보드의 헤더 |
| 2 | 메인 | PC · 메인, 모바일 · 홈 |
| 3 | 거래소 | PC · 거래소, 모바일 · 코인 상세 |
| 4 | 투자내역 | PC · 투자내역, 모바일 · 투자내역 |
| 5 | 랭킹 | PC · 랭킹, 모바일 · 랭킹 |
| 6 | 마이페이지 | PC · 마이페이지, 모바일 · 내 정보 |
| 7 | 나머지 화면: 커뮤니티(목록·상세·글쓰기), 공지, 최신동향, 로그인 | 시안 없음, 공통 컴포넌트로 조합 |
| 8 | 정리: 남은 CSS·티어 이미지·안 쓰는 아이콘 제거, preflight 켜기, 라이트·다크·모바일 전체 점검 | — |

각 단계는 `npm run build`와 `npm run lint`가 통과하고, 해당 화면을 라이트·다크와 PC·모바일 폭에서 확인한 뒤 커밋합니다.
